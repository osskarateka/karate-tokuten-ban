# 空手 得点板

空手の組手試合で使える、ブラウザだけで動く得点板アプリです。インストール不要・無料で使えます。

## 使い方

GitHub Pagesを有効にすると、下記のようなURLでそのまま使えます。

```
https://osskarateka.github.io/karate-tokuten-ban/
```

(リポジトリの Settings → Pages で、Branch を `main` / `/ (root)` に設定すると数分で公開されます)

## 機能

- 赤・青それぞれの「一本」「技あり」「有効」をタップで加点、合計得点を自動計算
- 先取(せんしゅ)の自動判定・手動切り替え
- カテゴリー(反則)表示(0〜4、色が変化)
- 試合タイマー(時間設定・スタート/ストップ・終了音)
- タイマー終了時に得点の高い方を自動でハイライト
- 全リセット機能

## ファイル構成

- `index.html` — アプリ本体(HTML/CSS/JSを1ファイルに同梱)

## カスタマイズ

タイマーの初期値や色などは `index.html` 内の `<style>` セクション、および `POINTS` 定数(一本=3点、技あり=2点、有効=1点)を編集することで変更できます。
